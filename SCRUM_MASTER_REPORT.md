# Scrum Master Report

**Project:** Intelligent Customer Request Processing  
**Framework:** Jira  
**Scrum Master:** TOUKBANI Oussama

## General Overview
The project was managed using the Scrum framework, with the work split into three main sprints. Each sprint had a clear goal and deliverables, allowing the team to move step by step from planning to implementation and final delivery.

My role focused on sprint planning, task organization, progress tracking, and ensuring that the team stayed aligned with the project objectives.

---

## Sprint 1: Planning & Setup (26-01-2026 / 27-01-2026)

### Sprint Objective
Set up the project foundation and prepare everything needed before development starts.

### Work Done
During this sprint, the team focused mainly on understanding the project and preparing the environment.

*   **Project Charter & PRD**: Defined the project scope and overall workflow.
*   **User Stories**: Identified user needs and translated them into basic user stories.
*   **Technology Selection**: Selected the main technologies to be used (Python, React, MySQL, LLM).
*   **Data Preparation**: Collected company policy data that will be used later for contract generation.

### Sprint Outcome
At the end of Sprint 1, the project vision was clear, tools were selected, and the team was ready to start development without blockers.

---

## Sprint 2: Core Development (Database & Frontend) (27-01-2026 / 28-01-2026)

### Sprint Objective
Build the technical base of the application and allow users to start interacting with the system.

### Work Done
This sprint was mainly focused on implementation.

*   **Repository Setup**: Created the GitHub repository and configured the development environment using VS Code.
*   **Company Policies Data**: Gathered and structured the company policy data for the AI.
*   **UX/UI Conception & Frontend Development**: Designed and created the frontend interface.
*   **Database Schema**: Designed and created the MySQL database and required tables.
*   **Quality Assurance / Testing**: Tested all forms and validation logic to ensure stability.

### Sprint Outcome
By the end of Sprint 2, the system had a working database, functional forms, and basic validation.

---

## Sprint 3: Generation & Finalization

### Sprint Objective
Deliver the main AI functionality and prepare the project for final delivery.

### Work Done
*   **Contract Generation**: Implemented AI logic to generate contracts based on user data and company policies.
*   **Contract Sending & Archiving**: Automated sending contracts via email and archiving documents for tracking.
*   **Final Testing & Fixes**: Tested the full workflow including forms, validation, AI generation, email delivery, and archiving.
*   **Documentation & Demo**: Prepared final documentation and recorded a demo video of the project.

### Sprint Outcome
The application became fully functional. Contracts could be generated, sent, and archived automatically. The project was ready for submission and demonstration.

---

## Scrum Master Notes
*   Sprint planning and reviews were done at the start and end of each sprint.
*   Tasks were adjusted when needed to avoid blockers.
*   Communication between technical and functional parts was maintained throughout the project.
*   The Scrum approach helped keep the work organized and predictable.
